隐私政策与零日志宣言

您的数字隐私是基本人权。乌龟加速从底层物理架构与传输协议出发，誓死捍卫您的个人隐私安全。

★ 我们的核心立足之本：严格的零日志政策

乌龟加速郑重承诺：我们绝不追踪、绝不记录、绝不存储、绝不向任何第三方转让或出售您的任何网络活动日志。我们在技术上从设计之初就确保了“无法提供根本不存在的数据”。

一、我们绝不收集和保留的使用日志

当您通过乌龟加速的专线隧道传输数据时，以下敏感信息在服务器端完全不保留且被实时丢弃：

  • 不记录浏览历史与访问网址：我们不知道、也无法查看您访问了哪些网站、观看了什么流媒体视频或下载了哪些文件。
  • 不记录网络流量载荷：所有数据经过军工级 AES-256-GCM 高度混淆加密，中继节点仅作为管道透明转发，无法解密您的通信报文。
  • 不记录用户真实原始 IP 地址：您的本地 IP 仅在建立连接握手瞬间用于通信路由，绝不会被写入任何永久存储介质。
  • 不记录节点分配的出站 IP：我们不保留哪个具体用户在哪一刻使用了哪个公网出口 IP 的对应映射关系表。
  • 不记录 DNS 查询请求：内置独家私有加密 DNS 转发解析体系，杜绝 ISP 运营商的域名劫持与 DNS 记录嗅探。
  • 不记录会话时间戳：我们不追踪记录您每次连接的开始时间、断开时间或具体在线持续时长。

二、RAM 纯内存无盘服务器技术架构

传统代理服务依赖普通机械硬盘或 SSD 运行，存在被取证或数据残留的物理风险。乌龟加速在所有核心专线中继节点推行“无盘纯内存运行系统”：

整个操作系统与中继程序均在挥发性随机存储器（RAM）中运行。这意味着服务器硬件上不存在持久化的存储媒介，一旦节点重启、断电或发生物理迁移，内存中的所有临时缓存数据将瞬间彻底灰飞烟灭，技术上杜绝任何物理层面的取证可能。

三、仅用于账户维护的极简必要数据

为了确保系统能向您正常提供付费订阅与售后服务，我们仅在用户注册与充值时收集以下极少量的必要信息：

  • 电子邮箱地址：仅用于登录身份鉴权、找回密码以及接收关键节点割接维护通知。我们鼓励用户使用具有高匿名性的临时邮箱或质优隐私邮箱注册。
  • 套餐计费状态与流量总数统计：仅用于计算您本月已使用的总流量数值（如已用 15GB / 剩余 105GB）以便限制超标，不包含任何具体的流量内容或访问去向分析。
  • 脱敏支付订单号：仅用于与第三方支付网关对账以确认激活您的套餐，我们不接触或存储您的任何银行卡号、CVV 码或支付密码。

四、无第三方广告与代码极简原则

乌龟加速官方推广落地页坚决践行极简主义，本站不加载任何第三方商业广告分析 SDK、不包含 Google Analytics / Facebook Pixel 等任何外链跨站追踪脚本。页面为纯原生 HTML 与 CSS 构建，杜绝任何利用 Canvas 指纹或客户端 Cookie 追踪用户行为的侵入式手段。
